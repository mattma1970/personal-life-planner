# PLP vault

The human-first, LLM-first persistence tier (PRD.md §5): Obsidian-compatible
markdown with YAML frontmatter, git-versioned, indexed by the PLP kernel.

- `gifts/`    — present ideas for the wife: occasion, budget, status (`idea → shortlist → bought → given`)
- `travel/`   — holiday plans and brainstorm results
- `goals.md`  — the life-scorecard goals (target hours per category)
- `notes/`    — freeform reference material

Rules: the PLP daemon is the only automated writer (atomic writes); on any
conflict a human edit of a file wins. Open this folder as an Obsidian vault
if you like — it is just markdown.
